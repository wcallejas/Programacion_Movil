Para el debido funcionamiento de esta app se deben tener en cuenta los siguientes criterios: 
1. Instalación del IDE Visual Studio Code con las respectivas extensiones implementadas.
   - Awesome Flutter Snippets
   - Atom One Dark Theme
   - Dart
   - Flutter
   - Flutter Widget Snippets
   - Material Icon Theme
   - Prettier
   - Indent Rainbow
   - Error Lens (Opcional)
2. Instalación de SDK de Flutter a partir del IDE o a partir de el archivo .zip obtenido de la documentación de Flutter: 
https://docs.flutter.dev/install
3. Instalación de Android Studio en su versión más reciente, para la cual se debe implementar una configuración que permita relacionar o enlazar un dispositivo móvil,
   Para esto se recomienda contar con un computador que como minimo disponga de 8GB de RAM, conectividad estable a internet, almacenamiento minimo de 50GB en Disco
   y configurar de tal manera un dispositivo en android Studio que permita el correcto funcionamiento de la App es decir que no sea tan reciente.
